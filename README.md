# vericairn-example-estate

> **A demonstration, under construction for the Vericairn 0.9.0 launch.** This is not a customer's estate, and its roles and device keys are demonstration-only.

The public example estate: a real [Vericairn](https://github.com/Vericairn/vericairn) estate that manages the example product [vericairn-example-app](https://github.com/Vericairn/vericairn-example-app), carrying a handful of work orders through recorded agent runs, reviews, acceptances and releases. When built, its records will be readable here as Markdown through generated registers, indexed by domain, and the estate will be upgraded with every Vericairn release.
